# GeoLab 原有实验 AGH 验证矩阵

每一行都在原 GeoSim 实验页中运行：原页面提供可视化与实时参数，AGH 面板读取参数，适配器生成科学数据和核验项。

| 原实验路由 | 原实验主题 | 可调变量 / 证据 | AGH 适配结果 |
|---|---|---|---|
| `required-02` | 太阳对地球的影响 | 纬度、直射纬度、云量；太阳高度、昼长、日辐射 | 3/3 核验 |
| `required-03` | 地层挖掘与地质年代复原 | 揭露层数、侵蚀、层序关系；相对年代证据 | 3/3 核验 |
| `required-04` | 地球的圈层结构 | 深度、P/S 波；圈层和物态推断 | 3/3 核验 |
| `required-05` | 大气成分与垂直分层 | 高度、纬度；温度和密度 | 3/3 核验 |
| `required-06` | 大气能量收支与热力环流 | 时段、云量、下垫面；温差和风向 | 3/3 核验 |
| `required-07` | 水循环过程与水量平衡 | 降水、植被、不透水面、土壤湿度；入渗和径流 | 3/3 核验 |
| `required-08` | 海水性质分布仿真 | 纬度、深度、温度/盐度/密度；剖面数据 | 3/3 核验 |
| `required-09` | 洋流分布与海浪潮汐 | 海盆、半球、风速、月相；洋流和潮差趋势 | 3/3 核验 |
| `elective-01`—`elective-07` | 原选择性必修一交互实验 | 地球运动、环流、锋面、地貌、水沙、灾害、海洋 | 统一 AGH 工具协议 |

## AGH 运行闭环

`自然语言问题 → Agnes 解析 → 实验规划 → 读取原页面参数 → geosim_run_original_experiment → 公式/边界/趋势核验 → 报告`

适配器输出的是教学计算证据，不冒充实时观测、专业水动力模型或灾害预报。
