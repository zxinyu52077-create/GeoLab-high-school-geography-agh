# GeoLab高中地理可验证仿真实验平台运行与复现说明

## 1. 启动原平台

```bash
npm install
npm run build
npm run dev
```

浏览器打开 Vite 提示的本地地址。进入流程为：欢迎页 → 学生/教师体验登录 → 选择教材 → 实验目录 → 任一原有实验页。

## 2. 使用 AGH 原有实验智能体

1. 进入必修一或选择性必修一的任一实验。
2. 点击页面右下角的“AGH 原实验智能体”。
3. 用自然语言输入探究问题，或使用当前实验的默认问题。
4. 点击“让 Agnes 设计并运行当前实验”。
5. 智能体依次展示：问题解析、实验规划、原实验运行、证据核验。
6. 查看数据表、公式、指标和核验结果，下载 JSON 数据证据或 Markdown 报告。

网页按钮通过 `/api/agh/experiments/run` 调用 GeoLab BFF。面板状态显示“GeoLab后台 → AGH 服务已连接”时进入 AGH 服务模式；显示“本地适配器预览”时是离线复现模式。本次提交包已附 `docs/GeoLab-AGH运行证据.json`、`docs/GeoLab-elective-07-AGH验证报告.md` 及无 Key 截图，证明一次真实 AGH 会话完成了规划、原实验运行和证据核验。

AGH 面板读取原实验页面正在使用的实时参数；用户拖动原有滑杆后再次运行，报告会随参数变化。原有 Three.js / SVG 仿真画面、读数和课堂诊断题保持不变。

## 3. 推荐录屏路径

1. 首页展示平台名称“GeoLab高中地理可验证仿真实验平台”和原有课程入口。
2. 选择“必修一” → “太阳对地球的影响”。
3. 先调节原有“观测纬度”“太阳直射纬度”“云量”，让画面和读数发生变化。
4. 打开 AGH 原实验智能体，输入：“比较南京、北京、哈尔滨在夏至和冬至的昼长，解释变化规律。”
5. 运行并展示 AGH 连续三步：规划 3×2 对照组、调用原实验计算 6 组数据、核验 3/3 规则通过。
6. 下载 JSON 证据，再切换“水循环过程与水量平衡”，展示同一 AGH 工具适配另一原实验。

## 4. 原实验复现样例

### 必修一实验 02：太阳对地球的影响

- 推荐 AGH 任务：南京、北京、哈尔滨 × 夏至、冬至，共 6 组对照。
- 计算结果：南京夏至昼长约 14.1 h、冬至约 9.9 h；哈尔滨夏至约 15.5 h、冬至约 8.5 h。
- 正午太阳高度：`h = 90° − |φ − δ| = 60°`。
- 昼长：`D = 24 arccos(−tanφ tanδ) / π = 12.0 h`。
- 日辐射相对值：对昼间入射角进行积分，再用云量作教学削弱项。

### 必修一实验 07：水循环过程与水量平衡

- 当前页参数：降水强度、植被覆盖、不透水面、前期土壤湿度。
- 入渗能力：随植被增加而增加，随前期土壤湿度增加而降低。
- 地表径流：不透水面增加、降水超过入渗能力时增加。
- 报告会同时显示降水、入渗、径流和径流率，避免只凭降水总量下结论。

## 5. 真实 AGH 接入

按 `docs/AGH-安全接入说明.md` 安装 `agh-plugin/geolab-tool/`，在 AGH Web/TUI 中配置 Agnes provider 和模型路由。模型 Key 只进入 AGH 私有配置，不写入本项目、截图或报告。
