# 选择性必修一实验母题依据

实验母题按人教版《自然地理基础》的章节组织：地球运动、地表形态塑造、大气运动、水的运动。七个实验保留现有名称，但将操作、观测证据和题目推理链重新对应到教材与高考常见设问。

## 教材和试题参照

- [人教版选择性必修一章节目录](https://planetgis.cn/downloads/dili-2019-xx1)：第一章地球的运动；第二章地表形态的塑造（构造地貌、河流地貌）；第三章大气的运动（常见天气系统、气压带和风带）；第四章水的运动（陆地水、洋流、海气相互作用）。
- [公开地理试卷（河流实验与阶地题，年份待核实）](https://cdn.gaokzx.com/zixunzhan/202403/c2294b8f-7ec8-4ccb-8df1-7c583742c617.pdf)：第 32—34 题以沙、水和河道模型考查颗粒搬运、沉积位置及河段判断；第 35—38 题用阶地高度、砾径和洪水位推断形成先后、稳定期与抬升期。这类题说明实验页要能改变条件、显示观测结果，并让学生据证据排除选项。
- [人教版教材资源目录（教育类院校）](https://www.jnnu.edu.cn/dlxy/info/1143/3062.htm)：用于核对出版社、教材册次和公开教材资源入口。

## 每个模型要练的推理

| 实验 | 模型操作 | 题目要练的证据链 |
| --- | --- | --- |
| 1 地球运动 | 改观测纬度、太阳直射纬度和地方时 | 杆高与影长 → 正午太阳高度 → 反推直射纬度；结合昼弧判断季节移动 |
| 2 气压带与风带 | 移动直射纬度、改变自转偏向与海陆温差 | 热源差异 → 气压梯度 → 近地面风向；再判断环流带季移或季风成因 |
| 3 锋面系统与气旋 | 推进锋线并读取多个气象站的连续变化 | 气温、气压、风向、降水的先后组合 → 锋面类型和过境天气；从低压槽判锋线位置 |
| 4 构造与地貌 | 改变挤压、伸展、错距和侵蚀历时 | 岩层弯曲/错断与新老关系 → 构造类型 → 侵蚀后的地貌；工程题还要检查岩性和地下水条件 |
| 5 河流地貌 | 改变坡度、流量、来沙、基准面和植被 | 流速与颗粒粒径 → 搬运能力/沉积位置 → 河段地貌；阶地高度和砾径 → 河流下切与地壳抬升阶段 |
| 6 地震与火山 | 推进 P、S 波并比较黏度与挥发分 | S−P 到时差 → 震中距 → 多台交会；高黏度和高挥发分 → 气体难逸出 → 爆炸性与灾害类型上升 |
| 7 洋流与水循环 | 改变赤道信风、辐射和入渗能力 | 风应力 → 暖水、温跃层和上升流 → 海温与降水区；能量输入和下垫面 → 蒸发、入渗、径流响应 |

题目采用原创变式，保留高考的材料判读、过程排序、控制变量和因果解释方式，不复制整道试题。模型数值用于说明趋势；地震波速、地形、锋面和海气过程均有实际区域差异。
