# 3–5 分钟演示讲解词

大家好，我们是地理智验队，作品是 GeoLab高中地理可验证仿真实验平台。它保留原 GeoSim 的课程目录、Three.js / SVG 仿真场景和变量控制，在原实验页上接入 Agnes 与 AGH，让学生可以用自然语言设计、运行和核验原有仿真实验。

现在进入必修一“太阳对地球的影响”。我先拖动观测纬度和太阳直射纬度，原有仿真画面会同步改变太阳光线、观测点、正午太阳高度、昼长和日辐射读数。

接下来打开右下角的“AGH 原实验智能体”，输入：“比较南京、北京、哈尔滨在夏至和冬至的昼长，解释变化规律。”Agnes 把问题交给 AGH，提取 3 座城市、2 个节气和需要计算的指标。

现在进入第二个连续步骤，AGH 调用原实验适配器运行计算，得到 3×2 共 6 组数据。结果表展示每座城市在夏至、冬至的正午太阳高度和昼长，公式也同时列出。这里的计算没有脱离原有实验页面，而是使用原实验的太阳高度与昼长模型。

第三个连续步骤是 `geolab_verify_experiment`。系统检查 6 组数据是否完整、昼长是否在物理边界内、夏冬昼长方向是否可解释；3/3 项通过后，Agnes 才组织结论。最后可以下载 JSON 数据证据和 Markdown 报告，报告包含问题、参数、公式、数据、核验和 AGH trace。

然后切换到原有“水循环过程与水量平衡”实验。改变降水、植被、不透水面和土壤湿度，AGH 会读取新的页面参数，计算入渗、地表径流和径流率。说明同一个 AGH 智能体不替换原实验，而是可以继续调度原平台的其他仿真。

因此 GeoLab 的核心是：原有仿真负责把地理过程可视化，Agnes 负责理解问题和设计方案，AGH 负责运行工具并留下证据，核验层负责判断结论是否越过科学边界。谢谢。
